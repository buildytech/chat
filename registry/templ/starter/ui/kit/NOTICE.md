# UI8Kit (vendored)

This directory is the generated UI8Kit templ kit (`github.com/ui8kit/codegen/generated/templ`),
vendored through a `replace` directive in the root `go.mod`. MIT License, UI8Kit.

Do not edit files here by hand. Build screens and blocks from these primitives
(`compose`, `icons`) and follow `.cursor/rules` (the UI8Kit contract). The kit was
generated with templ v0.3.1070, which is why `go.mod` pins that version.
