# Intent

SI Chat Website Builder — CMS-agnostic чат-билдер обычных страниц сайта (`page` + unique slug), рядом с visual Builder. Один Page Store, разные оболочки.

**P0:** runnable SPA (`apps/chat-web`), контракт портов, адаптеры-заглушки. Нет checkout/payment, нет fabricated promo/stock, нет multilanding/UTM.

**Targets:** browser SPA, WordPress embed, Wails3, Telegram Mini App.
